# 中文论文 / 报告 Word 通用版式规范

一套可直接套用的中文论文排版规则。**按「标题层级 + 段落角色」组织，不绑定任何
具体的章节安排** —— 论文有几章、章节叫什么名字都不影响套用。

**层级只有三级，三级之后直接是正文，不设四级标题。**

两套版式预设，按纸张分，各对应一份参考稿：

| 预设 | 参考稿 | 纸张 | 二级标题 | 行距 |
|---|---|---|---|---|
| `letter`（默认） | `总.docx` | Letter | 黑体四号 | 1.5 倍 |
| `a4` | `第四章　实验流程.docx` | A4 标准 | 楷体三号 + 缩进2字符 | 固定 28 磅 |

用 `--paper letter` / `--paper a4` 选择。

---

## 1. 标题层级

中文论文有两套常见编号习惯，本规范都认：

| 层级 | 中文式 | 数字式 |
|---|---|---|
| 一级 | 一、二、三、 | 1. / 第X章 |
| 二级 | （一）（二） | 1.1 / 4.1 |
| 三级 | 1. 2. 3. | 1.1.1 / 4.1.1 |

> **`1.` 在两套里含义不同**（中文式是三级、数字式是一级），所以 `cn_paper_docx.py apply`
> 会**先扫全文判断体系**再逐段分类：全文只要出现 `1.1` 这种两段式编号，就按
> 数字式处理。`一、`/`（一）` 和 `第X章` 在两种体系下都判为对应层级。

除上述编号外还识别：`壹、贰、`（大写中文数字）、`图3-1` / `图 3 xxx`（不带
章节号的图题）、`表2-1`、`Figure 3` / `Table 2`（英文题注）、
`Step 1：` / `第一步：` / `1：`（步骤行）。

### letter 版（对应「总.docx」）

| 层级 | 中文字体 | 字号 | pt | 加粗 | 首行缩进 | 行距 |
|---|---|---|---|---|---|---|
| 一级 | 黑体 | 三号 | 16 | 否 | 0 | 1.5 倍 |
| 二级 | 黑体 | 四号 | 14 | 否 | 0 | 1.5 倍 |
| 三级 | 黑体 | 小四 | 12 | 否 | 0 | 1.5 倍 |
| 正文 | 宋体 | 小四 | 12 | 否 | 2 字符 | 1.5 倍 |

### a4 版（对应「第四章　实验流程.docx」）

| 层级 | 中文字体 | 字号 | pt | 加粗 | 首行缩进 | 行距 |
|---|---|---|---|---|---|---|
| 一级 | 黑体 | 三号 | 16 | 否 | 0 | 固定 28 磅 |
| 二级 | **楷体** | 三号 | 16 | 否 | **2 字符** | 固定 28 磅 |
| 三级 | 黑体 | 小四 | 12 | 否 | 0 | 固定 28 磅 |
| 正文 | 宋体 | 小四 | 12 | 否 | 2 字符 | 固定 28 磅 |

> a4 版的一级与二级**字号相同**，靠「换字体（黑体→楷体）+ 首行缩进」区分层级，
> 这是参考稿的做法。letter 版则靠字号逐级下降区分。

### 两版共同

- 标题一律 **两端对齐、不加粗** —— 黑体本身就是粗笔画字体，再叠加加粗会发糊
- 标题都设「与下段同页」（keepNext），避免标题落在页底
- 段前/段后：一级 12/6 pt，二级 10/4 pt（a4 版 6/6），三级 8/4 pt（a4 版 6/3）
- 西文与数字一律 Times New Roman
- 标题默认**两端对齐**；要居中的标题（常见于「参考文献」「致谢」这类不参与编号的
  收尾章节）单独指定，不按名字自动判断：
  - `cn_paper_docx.py new`：写成 `#! 参考文献`（`#` 后加 `!`）
  - `cn_paper_docx.py apply`：加 `--center-titles "参考文献,致谢"`

## 2. 正文

| 项 | letter 版 | a4 版 |
|---|---|---|
| 中文字体 | 宋体 | 宋体 |
| 西文/数字 | Times New Roman | Times New Roman |
| 字号 | 小四（12 pt） | 小四（12 pt） |
| 行距 | 1.5 倍 | 固定 28 磅 |
| 首行缩进 | 2 字符 | 2 字符 |
| 对齐 | 两端对齐 | 两端对齐 |
| 段前 / 段后 | 2.5 pt / 0.5 pt | 2.5 pt / 0.5 pt |

**两个必须写对的地方：**

1. **首行缩进用字符单位**，要同时写两个属性：

   ```xml
   <w:ind w:firstLineChars="200" w:firstLine="480"/>
   ```

   `firstLineChars="200"` 是 2 字符（×100），`firstLine` 是等价 twips
   （2 字符 × 12 pt × 20 = 480）。只写一个，换台机器可能失效。

2. **多倍行距要关掉「对齐到网格」**，否则 1.5 倍会被文档网格拉成整数行高，
   版面看起来忽松忽紧：

   ```xml
   <w:snapToGrid w:val="0"/>
   ```

   固定值行距（exact）不受网格影响，可以不管。

**标题与正文的行距可分别覆盖**：`--line-heading` / `--line-body`，
写 `1.5` 是多倍行距，写 `28pt` 是固定值 28 磅。

## 3. 页面

| 项 | letter 版 | a4 版 |
|---|---|---|
| 纸张 | 8.5 × 11 in（Letter） | 21 × 29.7 cm（A4） |
| 上/下边距 | 3.5 cm | 3.5 cm |
| 左/右边距 | 3.0 cm | 2.8 cm |
| 页眉/页脚距边界 | 1.27 cm | 1.27 cm |

> **纸张注意**：Letter 比 A4 更宽、更矮，按 Letter 排的稿子打印到 A4 纸上会被
> 缩放。中文论文和国标赛事通常要求 A4。
>
> a4 版的页边距取自参考稿「第四章　实验流程.docx」（上下 3.5 / 左右 2.8），
> 不是 Word 默认的 2.54 / 3.18。

### 分栏

- `--columns 1`（默认）单栏；`--columns 2` 双栏。
- `--column-gap 0.75` 设置双栏栏间距（cm，默认 0.75）。
- 双栏只改栏数，字体、字号、行距、页边距、三线表等全部沿用所选预设。
- `new` 遇到 `@pagenum` 时：封面/目录所在节保持单栏，正文新节双栏；
  没有 `@pagenum` 时全文双栏。
- 双栏时插图按**单栏宽度**等比缩放；表格收进单栏宽度。
- `apply --columns 2` 把原文所有节设为双栏（适合没有封面/目录分节的稿子）。
- `verify 论文.docx --columns 2` 核对最后一节的栏数。

### 目录

- 插入的是真正的 Word 目录域（`TOC \o "1-3" \h \z \u`），不是死文本
- **域上不带 `w:dirty`**。带了 `dirty="true"` 会让 Word **每次打开文档都强制
  刷新目录**——用户手动更新再保存也没用，下次打开又刷一遍
- 生成时脚本自动调 Word 刷新一次并把结果存进文件，所以**打开即是带页码的
  正确目录，之后不会再变**
- 跳过自动刷新用 `--no-toc-refresh`，那就手动按一次 `F9`

### 页码

- 封面与目录**不编页码**；正文另起一节，页码从 **1** 重新开始
- 页脚居中，宋体五号
- 实现方式：`@pagenum` 处插入分节符（新页），新节设置 `w:pgNumType w:start="1"`

### 封面

居中排版，从上到下：留白两行 → 标题（黑体小二 22pt）→ 副标题（黑体三号 16pt）
→ 作者 / 单位 / 日期（宋体四号 14pt）。封面单独成页。

## 4. 图表

### 题注（两版相同）

| 项 | 值 |
|---|---|
| 字体 | **黑体**（西文 Times New Roman） |
| 字号 | 小四（12 pt） |
| 对齐 | **居中** |
| 首行缩进 | **0**（居中就不能再缩进） |
| 行距 | 1.5 倍；段前 3 pt，段后 6 pt |

- 编号：`图<章号>-<序号>` / `表<章号>-<序号>`，如 `图3-1`、`表2-4`
- **图题在图下方，表题在表格上方**（中文论文惯例）
- 常见坑：题注段落若既居中又带首行缩进，会整体右偏一点点

### 表注

`注：……` 置于表格下方，宋体五号、两端对齐、首行缩进 2 字符、单倍行距。

### 三线表

| 位置 | 线宽 | 样式 |
|---|---|---|
| 表格顶线 | 1.5 pt | 实线 |
| 表头下横线 | 0.5 pt | 实线 |
| 表格底线 | 1.5 pt | 实线 |
| 竖线 / 表内横线 | 无 | — |

- 表格整体居中
- 单元格内边距：上下 70 twips、左右 90 twips
- 单元格文字宋体五号居中，**表头行加粗**
- 表头行勾选「跨页重复」，长表格翻页后仍能看到列名

## 5. 其他段落角色

| 角色 | 写法 | 格式 |
|---|---|---|
| 封面 | `@cover` + `键: 值` 行 | 见上文「封面」 |
| 自动目录 | `@toc` | 标题黑体三号居中 + TOC 域（生成时自动刷新一次，见下） |
| 页脚页码 | `@pagenum` | 见上文「页码」 |
| 论文大标题 | `@title` | 黑体小二（18pt）居中 |
| 插图 | `[图3-1 说明](图.png)` | 居中，超出正文宽度时等比缩到正文宽 |
| 步骤行 | `- Step 1：…` | 左对齐、首行缩进 2 字符；序号黑体、内容宋体 |
| 引文 | `Quote-CN` 样式 | 楷体小四、左右各缩进 0.74 cm |
| 参考文献条目 | `[@] …` | 宋体五号、单倍行距、**不缩进**、左对齐 |

图片按 96 dpi 估算原始尺寸；比正文栏宽就等比缩小，否则用原始尺寸
（不放大，避免小图糊掉）。

步骤行适合实验流程、操作步骤这类「伪代码式 1、2、3…」的内容，比正文更易扫读。

## 6. 参考文献格式

- 位置：正文末尾
- 中文文献按 GB/T 7714
- 西文文献：作者**姓全大写 + 名首字母**，逗号分隔，三人以上用 `et al.`

```
PFURTSCHELLER G, LOPES DA SILVA F H. Motor imagery and direct
brain-computer communication[J]. Proceedings of the IEEE, 2001, 89(7): 1123-1134.
```

## 7. 本规范对参考稿做的通用性修正

两篇参考稿里有几处排版不一致，属常见问题，本规范统一处理：

| 现象 | 处理 |
|---|---|
| 同一份文档里两种标题格式并存（有的走 Heading 样式、有的手动设字体） | 统一走标准 Heading 样式，导航窗格可正常抓取，目录能自动生成 |
| Heading 3 样式残留 Word 默认的蓝色 `#4F81BD` + 主题字体 | 重置为规范内的黑体小四黑色 |
| 部分段落缺 `w:eastAsia`，在没装字体的机器上回退成「等线」 | 全部补齐中文字体 |
| 题注段落既居中又带首行缩进，导致右偏 | 取消缩进 |
| 表格边框风格不统一 | 统一为三线表 |
| 出现了「（1）」这类四级编号 | 降为正文（本规范只有三级） |

## 8. 适用范围与已知边界

**通用**（与具体项目无关）：页面设置、三级标题层级、正文缩进行距、图题表注、
三线表、步骤行、参考文献、封面、目录、页码、插图，以及按编号特征识别层级。
换任何一篇中文论文/报告都能套。

**边界**（这些会识别不了或需要手动收拾）：

| 情况 | 现状 |
|---|---|
| 字母编号 `A.` `A.1` | 不识别（中文论文少见） |
| 需要**四级以上**标题 | 本规范只有三级，四级会降为正文 |
| 正文**分栏**排版 | 支持单栏/双栏（`--columns 1|2`）；三栏以上、不等宽栏不支持 |
| 表格有**完整边框**（表单类、三线表以外） | 一律按三线表重排，表单类需事后手动改回 |
| **公文格式**（仿宋\_GB2312 三号、固定行距 28–30 磅、红头） | 不适用；a4 版的固定 28 磅行距接近，但字体不是仿宋 |
| **英文论文**（Times/Calibri、Figure/Table 编号） | 题注能认，但标题字体仍是中文的宋体/黑体 |
| 各校**专用封面**（校徽、表格化封面） | `@cover` 只是通用简版，专用封面要拿学校模板 |
| 旧版 `.doc` | 不支持，先用 Word 另存为 `.docx` |
| 引文、脚注尾注、页眉 | 未纳入 |

## 9. 未覆盖 / 需人工处理

- **引文段落**无法可靠自动识别，`cn_paper_docx.py apply` 不处理，
  需在 Word 里手动套 `Quote-CN` 样式。
- **脚注/尾注**格式未纳入，参考稿也没用。
- **页眉**未纳入（页码已支持，见「页码」一节）。
- **摘要 / Abstract / 关键词**就是普通的标题 + 正文，用 `# 摘要` 加正文即可，
  没有专门样式。
- **目录页码**要在 Word 里更新域才出现（`@toc` 插的是域，不是死文本）。
- **诚信承诺书、任务书**等各校专用前置页未纳入，格式各校不同。

## 10. 自定义参数（JSON 配置）

两套预设是默认值。用户要改字体、字号、行距、页边距、三线表线宽等，不必改代码：
导出一份 JSON，改完用 `--config` 读回来，其余项继承 `base` 预设。

主 skill：

```bash
python config_tool.py dump --paper a4 -o 我的版式.json
python new_paper.py 稿件.txt -o 论文.docx --config 我的版式.json
python apply_format.py 原稿.docx -o 排好版.docx --config 我的版式.json
python make_template.py --config 我的版式.json --out 模板.docx
python config_tool.py show 我的版式.json      # 查看合并后的完整数值
```

便携版：

```bash
python cn_paper_docx.py dump-config --paper a4 -o 我的版式.json
python cn_paper_docx.py new 稿件.txt -o 论文.docx --config 我的版式.json
python cn_paper_docx.py apply 原稿.docx -o 排好版.docx --config 我的版式.json
python cn_paper_docx.py template --config 我的版式.json -o 模板.docx
python cn_paper_docx.py spec --config 我的版式.json
```

最小配置示例：

```json
{
  "name": "my-school",
  "base": "a4",
  "label": "我的学校版式",
  "page": { "left_cm": 3.0, "right_cm": 3.0 },
  "body_line": "1.5",
  "headings": {
    "1": { "font": "黑体", "size_pt": 18 },
    "2": { "font": "黑体", "size_pt": 16 }
  },
  "roles": {
    "body": { "font": "仿宋", "size_pt": 14, "line": "1.5" },
    "caption": { "font": "楷体", "size_pt": 14 }
  },
  "table_lines": { "top": 2.0, "header": 0.75, "bottom": 2.0 }
}
```

| 段 | 字段 |
|---|---|
| `page` | `paper`（a4/letter）、`width_cm`、`height_cm`、`top_cm`、`bottom_cm`、`left_cm`、`right_cm`、`header_cm`、`footer_cm` |
| `headings` | `1` / `2` / `3`：`font`、`size_pt`、`bold`、`before_pt`、`after_pt`、`line` |
| 顶层 | `body_line`、`h2_indent_chars`、`columns`（1/2）、`column_gap_cm` |
| `roles` | `body`、`title`、`caption`、`note`、`reference`、`step`、`quote`、`table_cell`、`cover_title`、`cover_subtitle`、`cover_text` |
| `table_lines` | `top`、`header`、`bottom`（磅） |

角色字段：`font`、`ascii_font`、`size_pt`、`line`、`indent_chars`、`align`、
`before_pt`、`after_pt`；`step` 另有 `num_font`，`quote` 另有 `left_cm` /
`right_cm`，`table_cell` 另有 `bold_header`。

行距写 `"1.5"` 表示 1.5 倍，写 `"28pt"` 表示固定值 28 磅。只写要改的项，
其余继承 `base`；不写 `base` 时继承 `letter`。

便携版对应：`cn_paper_docx.py dump-config`、`--config 我的版式.json`、
`cn_paper_docx.py spec --config 我的版式.json`。
